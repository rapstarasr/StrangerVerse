# StrangerVerse

StrangerVerse is a real-time stranger chat experience with anonymous matching, rich messaging, voice notes, and video calling.

## Getting Started

Run the app locally:

```bash
npm install
npm run dev
```

Open https://www.strangerverse.online to explore the production experience, or use the local development server at http://localhost:3000.

## Highlights

- Anonymous stranger matching
- Rich conversations with text, files, voice, and video
- Real-time socket-based messaging and matchmaking

## Project Structure

- Frontend: app/
- Backend: backend/
- Shared UI and hooks: app/chat/
